Блиц-опрос

Интерфейс — GitHub Pages, обмен данными — сервер преподавателя (nginx).

Преподаватель
Создать комнату, запускать раунды (варианты — 20 с, текст — 40 с), группировать ответы студентов, отмечать правильный, смотреть итоги и группы.
Студент
Войти по коду комнаты, отвечать на время с обратным отсчётом, увидеть свой балл и группу: отлично / хорошо / удовлетворительно.
